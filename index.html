GraphBolt project

Real-world data is large and rapidly changing, and applications increasingly need analytics that reflect its latest state, quickly and correctly. The GraphBolt project enables real-time analytics on dynamic graphs, delivering high performance without sacrificing correctness.

GraphBolt/DZiG is an end-to-end system for streaming graph analytics with a stream ingestor, a dynamic graph store, and incremental graph engines. It provides a high-performance framework for writing new iterative graph analytics that run incrementally and in parallel with BSP guarantees, without exhaustive edge-level state tracking. The system is open source on GitHub.
